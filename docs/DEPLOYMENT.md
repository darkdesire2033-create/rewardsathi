# Deployment Guide

## GitHub Pages (Free)
1. Create repo: rewardsathi
2. Upload all files
3. Settings > Pages > Branch: main / root
4. Live at https://username.github.io/rewardsathi/

## Netlify (Recommended - Easiest)
1. Go to https://app.netlify.com/drop
2. Drag & drop index.html
3. Live instantly
4. Custom domain: Site Settings > Domain > Add custom domain

## Vercel
1. Go to vercel.com > Add New Project > Import GitHub repo
2. Framework: Other
3. Deploy

## Cloudflare Pages
1. dash.cloudflare.com > Pages > Create Project > Direct Upload
2. Upload index.html only (not ZIP)
3. Deploy
